Downloads that stay under your control

Jyroxa is an open-source download manager for Windows and Android. The Rust engine runs adaptive HTTP segments, BitTorrent and magnets, LinkGrabber extraction, tray and single-instance behavior, plus optional Telegram and browser handoff when you enable them.

What ships in the repo today

No bundled cloud account, no closed plugin store. Binaries come from GitHub Releases; the engine and UI source live in the same tree.

HTTP
Work-stealing segments, auto-tuned connection counts, .jxstate resume, mirrors, checksums, global and per-download caps.
Torrents
.torrent files and magnet URIs through embedded librqbit (DHT, LPD, PEX).
Browser
Chromium and Firefox extensions forward downloads via com.jyroxa.browser; optional video grab in extension options.
Desktop
LinkGrabber, scheduler windows, category filters including Video, clipboard monitoring, Settings tabs for paths, speed, and theme.
Android
Material 3 shell, foreground service, WorkManager resume after reboot, Wi‑Fi-only toggle.
CLI
jyroxa-cli for headless adds and engine control—same core crate as the GUI.
