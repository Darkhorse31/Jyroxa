Downloads that stay under your control

Jyroxa is an open-source download manager for Windows and Android. A Rust engine handles HTTP with adaptive multi-connection tuning, BitTorrent and magnets, LinkGrabber, tray integration, and optional Telegram and browser capture.

Download for Windows Android APK View on GitHub

BitTorrent (Debian 13.7.0 netinst ISO, same host): Jyroxa median ~50 MiB/s vs tuned aria2c ~15 MiB/s — see method.

Built for everyday use

HTTP that adapts

Work-stealing segments, auto-tuned connection counts, resume via .jxstate sidecars, and global or per-download speed limits.

BitTorrent in the app

Add .torrent files or magnet links. Peers, DHT, and LPD through the embedded librqbit stack.

Browser handoff

Chromium extension for Chrome, Edge, and Brave forwards downloads to the desktop app through the native messaging host.

More when you need it

LinkGrabber, category filters, download scheduler windows, optional Telegram media (feature telegram), light and dark UI themes.

Support development

Upstream hosting and release builds are funded by the maintainer. Sponsorship helps keep releases and benchmarks moving.
