## Implementation summary

- Start **8 connections** immediately; shared HTTP/1.1 segment client pool; **2 MiB** write batches.
- **Dynamic tail splits** (IDM-style) with `bounds` mutex so steals cannot overlap active ranges.
- Auto-tuner: baseline at 8, **trial double** only if aggregate rises ≥3% at the new count; **revert** failed trials (e.g. 16 when flat or slower); no shrink on noise; backoff only on 429/503/errors.
- Removed premature 8→16 ramp that had been hurting loopback and real hosts.
