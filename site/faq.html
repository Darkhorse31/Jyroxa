FAQ

Is Jyroxa free?

Yes. Jyroxa is open source under the MIT License. Binaries are published on GitHub Releases at no charge.

Which platforms are supported?

Windows desktop (installer and portable) and Android APK builds ship today. The engine and CLI are Rust and can be built from source on other targets; see the repository README.

Which video and audio sites can Jyroxa download from?

Examples include YouTube, Vimeo, Dailymotion, TikTok, Twitch, Instagram, Facebook, X (Twitter), Reddit, SoundCloud, Bandcamp, Bilibili, and Rumble. Jyroxa also supports direct MP4/WebM links and HLS or DASH sources when they are exposed by the page or URL. This uses the bundled yt-dlp extractors; login requirements, regional restrictions, and site changes can affect individual downloads. Browse the full supported-sites list.

How fast is it?

Throughput depends on your link and the remote server. Our published historical runs measured Jyroxa above an IDM 6.42 reference on two HTTP routes and above tuned aria2c 1.37.0 in one Debian torrent test on the same Windows PC. The comparison table and method name the versions and limits; these results do not prove Jyroxa is faster than every client or on every network.

Does Jyroxa use an API to speed up downloads?

No third-party acceleration API or proxy is used. HTTP speed comes from range requests, adaptive parallel connections, and segment work-stealing. The optional Telegram API is only for downloading Telegram media; it does not accelerate regular HTTP or torrent downloads.

Is Jyroxa faster than IDM or every torrent client?

Published historical benchmarks show higher throughput than the listed IDM 6.42 and aria2c 1.37.0 reference runs. They cover two HTTP servers and one BitTorrent swarm on one Windows PC—not every download manager, torrent engine, server, or network. Ghost Downloader has not been benchmarked.

Why doesn’t the browser extension see Jyroxa?

Usually the native host was not registered. Start the desktop app once, then fully restart the browser. See Install → Troubleshooting for “Host not registered”.

Can I use my own unpacked extension?

Yes. Load it unpacked, copy its ID into Jyroxa Settings → Browser, and ensure the native host allows that ID. The shipped build uses a fixed key and ID njgbdpacpmohafoefmcmnmhdjpjmjipe.

Where is Telegram support?

Behind the optional telegram Cargo feature. Sign in under Settings → Telegram with API credentials from my.telegram.org. See docs/TELEGRAM.md in the repo.
