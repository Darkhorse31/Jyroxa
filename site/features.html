Features

Each item below maps to code under crates/, apps/desktop, android/, or extensions/browser. Optional builds are marked.

Rust engine (jyroxa-core)

Shared by the Windows shell, Android JNI bridge, and CLI.

  • Adaptive multi-connection HTTP with an auto-tuner that retries wider counts and rolls back failed trials
  • Per-segment HTTP/1.1 with work-stealing when the server advertises ranges
  • 429/503 handling, Retry-After backoff, stall detection
  • Resume via .jxstate sidecars (reads legacy .sgstate)
  • Multi-mirror racing, MD5/SHA-256 verification, global and per-download speed limits
  • LinkGrabber: extract, probe, filter, and package links from pages or pasted text

BitTorrent and magnets

Add torrent files or magnet URIs from the main window or CLI. Peers, DHT, LPD, and PEX go through embedded librqbit. BEP-19 web seeds via the HTTP multi-connection path are not in v0.1.8.

Measured on Debian 13.7.0 amd64 netinst (~756 MiB): Jyroxa median ~16.4 s / ~50 MiB/s; aria2c 1.37.0 with tuned flags ~50 s / ~15 MiB/s (three runs each, same Windows host). Source: reports/torrent-bench-0.1.8.tsv.

Windows desktop (Tauri)

  • Sidebar categories, search, sort, bulk actions, drag-and-drop, context menu
  • LinkGrabber panel, Quick Video category on add-download, tray icon, start with Windows
  • Prevent sleep while downloading, auto-resume on launch, single-instance mutex
  • Native notifications, light/dark UI themes (warm dark matches this site’s default)
  • NSIS installer and portable ZIP with WebView2Loader.dll and jyroxa-native-host.exe

Browser extension

  • Chrome, Edge, Brave (Chromium WebExtension), and Firefox packages in releases
  • Intercepts downloads and sends them to com.jyroxa.browser via native messaging
  • Official Chromium extension ID njgbdpacpmohafoefmcmnmhdjpjmjipe
  • Optional video grab and file-type filters (videoGrabEnabled)
  • Hold Alt when clicking a link to skip interception for about 30 seconds

Telegram (optional build)

Cargo feature telegram — resolve public and signed-in posts via grammers. Configure under Settings → Telegram; see docs/TELEGRAM.md.

Android

  • Material 3 UI with dynamic color
  • Foreground download service with pause/cancel actions in the notification
  • WorkManager resume after reboot; Wi‑Fi-only option in settings
  • Universal APK from GitHub Releases

Open source and releases

MIT License. Build from source with the GNU toolchain flow in docs/BUILD_WINDOWS_GNU.md or Gradle for Android. Tagged releases ship installers, portable ZIP, extension archive, APK, and SHA256SUMS.txt.
