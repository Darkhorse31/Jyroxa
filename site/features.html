Features

Everything listed here exists in the repository today. Optional components are called out explicitly.

Adaptive multi-connection HTTP

  • Auto-tuner probes wider connection counts and reverts failed trials
  • Per-segment HTTP/1.1 with work-stealing when servers support ranges
  • 429/503 backoff, stall detection, mirrors, and checksum verification

BitTorrent and magnets

  • Add torrent files or magnet URIs from the main window
  • librqbit backend (DHT, LPD, PEX); no BEP-19 web seeds via HTTP engine in v0.1.8

Measured on Debian 13.7.0 amd64 netinst (~756 MiB): Jyroxa median ~16.4 s / ~50 MiB/s; aria2c 1.37.0 with tuned flags ~50 s / ~15 MiB/s (three runs each, same Windows host). Source: reports/torrent-bench-0.1.8.tsv.

Browser extension

  • Chrome, Edge, Brave (Chromium WebExtension), and Firefox builds in releases
  • Intercepts downloads and sends them to com.jyroxa.browser via native messaging
  • Stable Chromium extension ID njgbdpacpmohafoefmcmnmhdjpjmjipe
  • Optional video grab and file-type filters (videoGrabEnabled)

Desktop workflow

  • LinkGrabber, drag-and-drop, bulk actions, tray icon, start with Windows
  • Quick category buttons including Video on the add-download panel
  • Light/dark themes, native notifications, single-instance mutex

Download scheduler

  • Settings → Scheduler: start/stop times and days of week
  • Persisted in desktop engine settings (scheduler_start, scheduler_stop, scheduler_days)

Telegram (optional build)

  • Cargo feature telegram — resolve public and signed-in posts via grammers
  • Settings → Telegram for API credentials and session
  • Documented in docs/TELEGRAM.md

Android

  • Material 3 UI, foreground download service, WorkManager resume
  • Universal APK from GitHub Releases
