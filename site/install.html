Install guide

Pick an artifact from GitHub Releases. Verify checksums with SHA256SUMS.txt when provided.

Windows installer

  1. Download Jyroxa_*_x64-setup.exe and run the NSIS installer.
  2. The installer places jyroxa-desktop.exe and registers the native messaging host for the browser extension.
  3. On first launch, allow notifications if you want download-completion toasts.

Portable ZIP

  1. Extract Jyroxa-*-windows-x64-portable.zip to a folder you control.
  2. Keep Jyroxa.exe, WebView2Loader.dll, and jyroxa-native-host.exe in the same directory.
  3. Run Jyroxa.exe once so the host manifest is written under your user profile.

Browser extension

  1. Download jyroxa-browser-extension.zip and extract it, or clone extensions/browser.
  2. Build or install the desktop app first; start it once so com.jyroxa.browser is registered.
  3. Chrome / Edge / Brave: open chrome://extensions or edge://extensions → Developer mode → Load unpacked → select the extension folder.
  4. Firefox: about:debugging → This Firefox → Load Temporary Add-on → manifest.json.
  5. In Jyroxa → Settings → Browser, paste the extension ID if you use a custom unpacked build. Official Chromium ID: njgbdpacpmohafoefmcmnmhdjpjmjipe.
  6. Hold Alt while clicking a link to skip interception for about 30 seconds.

Troubleshooting

“Host not registered” in the extension popup means Chromium cannot find com.jyroxa.browser.
  1. Install or update the desktop build and launch Jyroxa once (portable: run from the folder that contains jyroxa-native-host.exe).
  2. Quit and reopen the browser completely—not only the tab—so it reloads native messaging manifests.
  3. If you moved the portable folder, run Jyroxa again from the new path to rewrite the host registration.
  4. Check that Settings → Browser lists your extension ID when using a non-default unpacked build.

For other errors (“Extension not allowed”, timeouts), see FAQ or extensions/browser/native.js failure strings in the repository.

Android

  1. Install Jyroxa-*-android-universal.apk from Releases (enable install from unknown sources if needed).
  2. Grant notification permission for the foreground download service.
